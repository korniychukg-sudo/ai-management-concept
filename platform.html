Как устроена

Что сделано с нуля

  • Бэкенд на Python и FastAPI, Docker Compose на своём сервере
  • Синхронизация звонков из amoCRM по расписанию для всех клиник
  • Промпты и критерии AI-оценки звонков, типизация звонков
  • Расчёт конверсии в запись по данным CRM
  • Кабинет клиники с ролями, отчёты PDF и Excel, боты с ежедневными итогами
  • Голосовой AI-тренажёр, где администраторы отрабатывают звонки с виртуальным пациентом

Что взято готовым

  • amoCRM и телефония клиник как источники
  • ElevenLabs для распознавания речи
  • OpenAI для анализа и голосового режима тренажёра
  • Yandex DataLens для управленческих дашбордов
  • MongoDB, PostgreSQL, Prometheus, nginx

Роли

  • Администратор платформы: подключение клиник, лимиты, повторная обработка
  • Руководитель клиники: кабинет, дашборды, отчёты по администраторам
  • Наблюдатель тренажёра: результаты попыток и прогресс сотрудников
  • Администраторы клиник: проходят голосовой тренажёр
